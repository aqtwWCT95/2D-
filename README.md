# 🌍 2D 生存沙盒 (2D Survival Sandbox)

一个基于 Python 和 Pygame 开发的 2D 侧视角生存沙盒游戏。灵感来源于《我的世界》与《泰拉瑞亚》，支持单机生存与多人联机。



## ✨ 核心特性

- **🎮 经典 2D 生存玩法**：挖掘、放置、合成、建造，体验从徒手撸树到钻石套的完整成长线。
- **⚔️ 丰富的内容**：包含工作台（2x2与3x3）、熔炉烧炼系统、武器/工具等级、护甲减伤、昼夜交替、以及随机生成的动物与夜晚怪物。
- **🌐 多人联机与防作弊**：
  - 采用 **TCP Socket** 架构，服务端权威判定。
  - 服务端严格校验挖掘、放置、攻击的距离（防瞬移、防超距操作）。
  - 支持**服务器列表**与实时 **MOTD (服务器标语)** 显示。
  - **玩家位置云端保存**：每次退出游戏自动将坐标存入服务端，下次登录原地复活。
- **⚙️ 高度可配置**：服务端自带 `server_config.json` 配置文件，支持自定义白名单、MOTD 和交互距离。
- **🎨 自定义贴图**：所有方块和物品图标均支持从 `assets/` 目录读取（如果没有，将自动生成占位图）。你可以自由替换为自己画的像素图！
- **📦 一键打包**：支持使用 PyInstaller 打包成独立的 `.exe` 运行文件。

## 🛠️ 环境要求

- Python 3.8+
- Pygame 2.6.0+
